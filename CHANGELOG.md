# Changelog

## [2.0.0] - 2025-04-26
### Added
- Multi-resolution data: daily, monthly, annual (2025-2055)
- 557 communes of Senegal with GPS coordinates
- CMIP6 climate projections (SSP1-1.9, SSP2-4.5, SSP5-8.5)
- QGIS plugin with 4 tabs
- Streamlit dashboard with 8 pages
- FastAPI REST API with 50+ endpoints
- React Native mobile app + PWA
- LSTM + Random Forest ML models
- Docker + Kubernetes deployment
- Complete CI/CD with GitHub Actions

## [1.0.0] - 2024-12-01
### Added
- Initial QGIS plugin structure
- Basic climate simulation
